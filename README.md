# Модель для классификации кошек и собак

Репозиторий включает в себя модель классификации кошек и собак, а также веб интерфейс для быстрой проверки модели.

## Модель

Обучена на данных [kaggle dogs vs cats](https://www.kaggle.com/c/dogs-vs-cats).

## Веб интерфейс
